你说得对，树莓派 5 的官方风扇是支持调速的（通过 PWM 控制），默认是根据温度自动调节转速。如果你希望它**始终全速运转**（最大风力 + 最佳散热），可以通过修改配置文件来实现：

------

## ✅ 修改风扇为恒定满速运行

### 步骤 1：编辑配置文件

```bash
sudo nano /boot/firmware/config.txt
```

在文件底部或合适位置加入以下内容（或修改已有的相关项）：

```ini
# 强制风扇开启并全速运行
dtparam=fan_ena=1
dtparam=fan_temp0=0
dtparam=fan_temp0_hyst=0
dtparam=fan_temp1=0
dtparam=fan_temp1_hyst=0
```

> 这段配置的含义是：
>
> - `fan_ena=1`：启用风扇控制
> - `fan_temp0/1=0`：把温度阈值都设为 0°C，系统一启动就判定“温度太高”，从而让风扇保持最高速
> - `*_hyst=0`：防止风扇降速的回差

------

### 步骤 2：保存并重启

按 `Ctrl+O` 保存，`Ctrl+X` 退出，然后重启：

```bash
sudo reboot
```

------

## ✅ 验证风扇转速是否生效

在开机后几秒钟内你应该能**听到风扇明显的最大转速声音**。此外你可以通过 GPIO 的电压或 GPIO 波形工具确认风扇 PWM 输出为常高（100% 占空比）。

------

## ✅ 附加建议

如果你担心长期满速噪音太大，但又希望更快启动风扇，可以把阈值设为较低温度：

```ini
dtparam=fan_temp0=30
dtparam=fan_temp1=35
```

这表示 30°C 开启风扇低速，35°C 转最大速。

------

## 最终在树莓派上应用

```
[all]
dtparam=cooling_fan=on
dtparam=fan_temp0=36000,fan_temp0_hyst=2000,fan_temp0_speed=100
dtparam=fan_temp1=40000,fan_temp1_hyst=3000,fan_temp1_speed=150
dtparam=fan_temp2=50000,fan_temp2_hyst=4000,fan_temp2_speed=200
dtparam=fan_temp3=55000,fan_temp3_hyst=5000,fan_temp3_speed=255
usb_max_current_enable=1
```
